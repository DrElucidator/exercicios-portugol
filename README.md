# Exercícios em Portugol

Projetos criados antes do início da formação na Academia do Programador. O repositório reúne exercícios de lógica, condições, cálculos, repetição e pequenos jogos feitos em Portugol.

## Projetos

| Arquivo | Descrição |
| --- | --- |
| `Adivinhação.por` | Jogo de adivinhar um número entre 1 e 20, com níveis de dificuldade, limite de tentativas e pontuação. |
| `Calculadora simples 1.0.por` | Primeira versão de uma calculadora com as quatro operações básicas. |
| `Calculadora simples 2.0.por` | Evolução da calculadora, com validação de divisão por zero e mensagens por operação. |
| `Classificador de triângulos 1.0.por` | Valida os lados informados e classifica o triângulo como equilátero, isósceles ou escaleno. |
| `Triângulo_Simples.por` | Versão inicial e mais direta do classificador de triângulos. |
| `Inicio da corrida.por` | Protótipo de uma corrida baseada em sorteio de dados. |
| `corrida por IA.por` | Jogo de corrida entre jogador e computador, com dado, casas de bônus e penalidades. |
| `Forca.por` | Jogo da forca com palavras de frutas, tentativas e escolha aleatória de palavra. |

## Como executar

1. Instale o [Portugol Studio](https://portugol.dev/).
2. Clone este repositório ou faça o download dos arquivos.
3. Abra o arquivo `.por` desejado no Portugol Studio.
4. Execute o programa pelo botão **Executar** ou pela tecla `F9`.

Cada arquivo é independente; não há dependências ou configuração adicional.
