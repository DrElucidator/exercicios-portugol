# Exercícios em Portugol

Exercícios criados antes do início da formação na Academia do Programador. Este repositório registra os primeiros estudos de lógica, condições, cálculos e pequenos jogos usando Portugol.

## Exercícios

- Adivinhação
- Calculadora simples 1.0 e 2.0
- Classificador de triângulos
- Corrida por IA
- Forca
- Início da corrida
- Triângulo simples

## Como executar

Abra qualquer arquivo `.por` em um interpretador compatível com Portugol/Visualg e execute-o localmente.

## Contexto

Este material é um registro de aprendizado inicial, preservado como parte do meu portfólio de evolução em programação.
